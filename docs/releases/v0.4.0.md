# QueryAssure v0.4.0 — Pytest for SQL Agents

QueryAssure v0.4.0 makes the value of SQL Agent testing visible in one command.

```bash
uvx --from git+https://github.com/Victoria824/QueryAssure queryassure demo
```

The demo generates deterministic Northstar Retail data, runs five golden contracts,
injects a plausible schema hallucination, and proves that the release gate blocks it.
No API key, Docker Engine, or external database is required.

## Highlights

- one-command zero-key regression demo
- self-contained, shareable HTML evidence reports
- project scaffolding with `queryassure init`
- six-case adversarial mutation challenge
- JSON and HTML artifacts from the reusable GitHub Action
- escaped untrusted agent output in generated reports

## Install

```bash
pip install https://github.com/Victoria824/QueryAssure/releases/download/v0.4.0/queryassure-0.4.0-py3-none-any.whl
queryassure demo
```

The hosted SQL Agent playground remains available at
[victoria824.github.io/QueryAssure](https://victoria824.github.io/QueryAssure/).
