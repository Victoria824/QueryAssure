# QueryAssure v0.5.0 — Enterprise Agent Assurance

QueryAssure v0.5.0 expands beyond SQL-specific checks with framework-neutral workflow
contracts and a Microsoft 365 reference agent.

## Added

- generic `WorkflowTrace`, ordered audit events, and `WorkflowEvaluationRunner`
- required/forbidden tool-call and least-privilege OAuth scope contracts
- human approval gates for external side effects
- audit completeness and credential leakage checks
- Outlook email triage, reply-draft, and approval-gated send patterns
- approval-gated Microsoft Teams notifications
- deterministic Microsoft Graph simulator and fail-closed live Graph client
- zero-key `queryassure m365-demo` command and four enterprise workflow contracts
- interactive Microsoft 365 Agent experience in the public playground

## Try it

```bash
uvx --from git+https://github.com/Victoria824/QueryAssure queryassure m365-demo
```

The demo does not require a Microsoft tenant or API key. Live Graph access remains
disabled unless explicitly enabled, and OAuth tokens never enter traces or reports.
